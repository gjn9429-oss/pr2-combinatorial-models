Установлення бібліотеки:

```powershell
python -m pip install matplotlib
```

## Запуск

Виконувати з основної папки проєкту:

```powershell
python main.py
python block2.py
python block3.py
python block4.py
```

Кожна команда запускає окремий блок.

## Зміст

- main.py — блок 1: колізії, 365 можливих значень, по 10 000 експериментів для кожного k.
- block2.py — блок 2: паролі без повторення символів, 100 000 експериментів.
- block3.py — блок 3: геометрична ймовірність, від 100 до 1 000 000 точок.
- block4.py — блок 4: покриття конфігурацій набором із 9 сценаріїв, 10 000 експериментів.

Результати виводяться в термінал.
Блок 3 зберігає графік у graphics/block3_convergence.png.
Для завершення блоку 3 потрібно закрити вікно графіка.

Через випадкову генерацію результати різних запусків можуть відрізнятися.
