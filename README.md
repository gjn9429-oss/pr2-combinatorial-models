## Залежності

Python 3.10 або новіший, matplotlib.

```powershell
python -m pip install matplotlib
```

## Запуск

З основної папки проєкту запустити всі блоки:

```powershell
python src/main.py
```

Або запустити потрібний блок окремо:

```powershell
python src/block1.py
python src/block2.py
python src/block3.py
python src/block4.py
```

## Блоки роботи

- `src/block1.py` — колізії: 365 можливих значень, по 10 000 експериментів для кожного k.
- `src/block2.py` — паролі з шести різних символів, 100 000 експериментів.
- `src/block3.py` — геометрична ймовірність, від 100 до 1 000 000 точок.
- `src/block4.py` — повний збіг конфігурації з одним із дев’яти сценаріїв Pairwise, 10 000 експериментів.

Результати виводяться в термінал. Блок 3 також зберігає графік
`graphics/block3_convergence.png` без відкриття окремого вікна.

У `results/` збережено результати, наведені у звіті; у `report/` — звіт у PDF.
Нові запуски можуть дати інші частоти та оновлюють графік блоку 3.
